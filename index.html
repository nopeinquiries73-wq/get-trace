Setup

  1. Only use the Download loader button on this page. File: get-trace.onrender.com/loader.exe. Anything else named TRACE is not this build.
  2. Join the Discord for status before you run a new drop. Invite: discord.gg/HXh976tyEP
  3. Close extra Roblox windows. Leave one RobloxPlayerBeta session on the desktop, not fullscreen exclusive if the overlay fails to sit on top.
  4. Run loader.exe. If Windows asks for elevation, accept. The loader checks version, writes under %LOCALAPPDATA%\Trace\<version>\, then starts TRACE.
  5. Wait until the small TRACE window says starting and closes. If it stays on checking, you are offline or the host is down — try again later, do not grab a random exe.
  6. In game: F1 opens the panel, F2 unloads. RMB or controller right trigger aims. Left trigger is triggerbot when a pad is connected.
  7. If Windows Protection / SmartScreen stops the file, that is Windows classifying it. Allow it in Protection history on your own PC or do not run it. TRACE does not switch security software off.
  8. After an update, bump happens from trace.txt on the host. Old version folders under %LOCALAPPDATA%\Trace are removed by the loader.
